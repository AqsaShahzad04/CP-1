# healthBridge — AI Health Assistant

> Final Year Project (FYP) · Bachelor of Science in Computer Science

---

## Project Overview

**healthBridge** is an AI-powered health assistant designed to make reliable medical information accessible to everyone. The system uses an AI model trained on medical knowledge to answer patient queries, assist with symptom analysis, and guide users toward appropriate care — reducing dependency on costly consultations for basic health questions.

This repository contains all academic and design documentation for the FYP, including the official SRS, design documents, and weekly progress reports submitted to the university supervisor.

## Problem Statement

In Pakistan, access to reliable medical information is limited by cost, geography, and availability of qualified professionals. healthBridge aims to bridge this gap by providing an AI assistant that can answer common health questions accurately, cite trustworthy medical sources, and know when to escalate to a human professional.
